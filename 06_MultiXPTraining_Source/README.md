# Multi XP - Training v1.0 RC2

RC2 is the quality-assurance candidate for Multi XP - Training.

No intended gameplay behavior has changed from RC1. RC1 already confirmed all 15 vanilla training devices and the added XP engine. RC2 freezes that implementation and focuses on reproducible release testing.

## Supported vanilla equipment

- Training Dummy Mk I-III
- Training Turret Mk I-III
- Lockpicking Training Kit I-III
- Assassination Training Dummy I-III
- Thievery Training Box I-III

## Default added XP

- Training Dummy: Melee Defense and Dodge, multiplier 1.0, caps 5 / 10 / 15.
- Training Turret: Crossbows, Precision Shooting and Perception, multiplier 1.0, caps 10 / 20 / 30.
- Lockpicking, Assassination and Thievery devices: optional Dexterity fields exist but remain disabled by default.
- Optional attributes, combat skills and weapon categories remain disabled by default.

## RC2 policy

- No new gameplay features.
- Bug fixes only.
- SourceData format remains compatible with RC1.
- Build with Release | x64 using Visual Studio 2010 v100.
