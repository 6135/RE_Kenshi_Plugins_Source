# Guard Break & Bash v1.0.0

RE_Kenshi + KenshiLib向けの戦闘拡張プラグインです。

防御成功時に、能力差に応じて2種類の追加怯み判定を行います。

## Bash

防御側が攻撃側の体勢を崩します。

- 発動側参照: 筋力・器用さ・打たれ強さの最大値
- 抵抗側参照: 筋力・器用さ・打たれ強さの最大値

## GuardBreak

攻撃側が防御側を押し崩します。

- 発動側参照: 筋力・器用さの最大値
- 抵抗側参照: 筋力・器用さ・打たれ強さの最大値

## 暫定標準設定

`BalancePreset=1`

| スキル差 | 発動率 |
|---:|---:|
| -60以下 | 2.5% |
| -30 | 7.5% |
| 0 | 17.5% |
| +30 | 35.0% |
| +60以上 | 47.5% |

プリセット:

- `0`: 完全カスタム
- `1`: おすすめ・二段階カーブ
- `2`: 成長重視
- `3`: バニラ型
